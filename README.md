Este es un proyecto personal hecho completamente para practicar React y las peticiones a API utilizando Axios. También me ha servido para descubrir nuevas webs donde se pueden hacer cosas súper interesantes, como desplegar una base de datos y, a partir de ahí, crear una API para luego utilizarla en la web final.

El nombre del proyecto es PAM (Proyecto Adopta Miradas).
Las herramientas empleadas en este proyecto son las siguientes:

  React: Como biblioteca para la maquetación web, ya que es la tecnología que actualmente estoy 
  estudiando y practicando.

  Express.js: Este es el framework que he utilizado para crear la API de la web, aprovechando una plantilla 
  para agilizar el proceso.

  Vercel: Es la plataforma donde he hecho el despliegue tanto de la web como de la API, ya que tiene 
  muy buena compatibilidad con Express.js y porque la base de datos está creada en Neon.tech, web que se 
  integra perfectamente con Vercel.

  Neon.tech: Plataforma en la cual se ha creado la base de datos utilizando PostgreSQL, debido a su facilidad 
  de uso y excelente compatibilidad con Vercel.
